# Hi, I’m Mason

I’ve worked with data since my first finance role. At NAMO, I analyzed budget variances and cash flow, built forecasts, and presented KPI dashboards to executives. In Ulaanbaatar’s municipal government, I analyzed more than a million financial records and cut recurring report preparation from about 12 hours to two.

I’m pursuing an M.S. in Data Analytics at the University of the Potomac. My recent work includes checking healthcare data with SQL, building Power BI reports with row-level security, and reconciling bank data for compliance reporting.

## Selected projects

- [Metrobus Operations Analytics](https://github.com/MUNKHNASANOTGONBOLD/dmv-bus-operations). I collected about a day of live bus positions and used SQL to account for repeat observations before comparing reported schedule deviations.
- [Consumer Complaint Early Warning](https://github.com/MUNKHNASANOTGONBOLD/Customer-Complaint). I built a Python and SQLite workflow that flags changes in public credit-card complaints and shows the evidence behind each flag.
- [World Bank IDA Portfolio](https://github.com/MUNKHNASANOTGONBOLD/The-Anatomy-of-a-World-Bank-Loan). I cleaned 11,404 financing records and built a Power BI-ready model and HTML dashboard prototypes.
